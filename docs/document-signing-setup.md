# חתימת מסמכים: הגדרה והפעלה

## איך זה עובד

1. **`/admin`**: פורטל ניהול עם סיסמה, למשתמש אחד.
   - **תבניות**: מעלים פעם אחת את ה-PDF של ייפוי הכוח ומסמנים עליו בעכבר את השדות של פרטי הלקוח (שם, ת.ז., כתובת…) ואת מקום החתימה.
   - **מסמך חדש**: ממלאים את פרטי הלקוח. הפרטים נכתבים לתוך ה-PDF ומתקבל קישור ייחודי שאפשר להעתיק או לשלוח בוואטסאפ.
   - **מסמכים**: רואים את הסטטוס של כל מסמך (ממתין / נחתם / פג תוקף), צופים ב-PDF, שולחים שוב למייל או מוחקים.
2. **`/sign/<token>`**: הקישור שהלקוח מקבל, עם 256 ביט אקראיים כך שאי אפשר לנחש אותו. הלקוח יכול לחתום רק במסגרות שסימנת, בציור או בהקלדת שם. אחרי החתימה הקישור נסגר לחתימה נוספת.
3. **אחרי החתימה**: השרת מטמיע את החתימה ב-PDF ומוסיף בסופו עמוד אישור חתימה עם תאריך, IP, מכשיר ו-SHA-256 של המסמך המקורי. הקובץ נשלח ל-`NOTIFY_EMAIL` דרך Resend.

הקישור בתוקף 30 יום (`SIGN_LINK_TTL_DAYS`).

## הגדרה חד-פעמית ב-Cloudflare

### 1. R2 (אחסון הקבצים)
- Dashboard → **R2** → Create bucket בשם **`refoundit-docs`**.
- מומלץ: Settings → **Object lifecycle rules** → מחיקה אוטומטית אחרי 90 יום. הקבצים מכילים פרטים אישיים של לקוחות, ואחרי שהמסמך נשלח במייל אין סיבה לשמור אותם לנצח.
- Pages project → Settings → **Bindings** → R2 bucket: שם המשתנה `DOCS_BUCKET` ← `refoundit-docs`. אם הפרויקט מנוהל דרך `wrangler.toml`, ה-binding כבר מוגדר בו.

### 2. Resend (שליחת המייל)
- נרשמים ב-[resend.com](https://resend.com) → **Domains** → מוסיפים את `refound-it.com` ומעתיקים את רשומות ה-DNS שהם נותנים ל-Cloudflare DNS.
- **API Keys** → יוצרים מפתח עם הרשאת Sending בלבד.
- כתובת השולח מוגדרת ב-`MAIL_FROM` בקובץ `wrangler.toml` (`documents@refound-it.com`) וחייבת להיות על הדומיין המאומת.

### 3. סודות (Secrets)
Pages project → Settings → **Variables and Secrets** → מוסיפים כ-**Secret** (מוצפן), גם ל-Production וגם ל-Preview:

| שם | ערך |
|---|---|
| `ADMIN_PASSWORD` | סיסמה חזקה לפורטל (16 תווים ומעלה) |
| `SESSION_SECRET` | מחרוזת אקראית של 32 תווים לפחות. אפשר לייצר עם `openssl rand -base64 48` |
| `RESEND_API_KEY` | המפתח מ-Resend |

> אסור לשים את הערכים האלה בקוד או ב-git. `.dev.vars` (לפיתוח מקומי) כבר נמצא ב-`.gitignore`.

### 4. הגנה נוספת (מומלץ)
- **Rate limiting**: Security → WAF → Rate limiting rules → `/api/auth/login`, למשל 5 בקשות לדקה ל-IP.
- **Cloudflare Access** (חינמי): אפשר להגן על `/admin*` ו-`/api/admin/*` עם קוד חד-פעמי למייל, כשכבה נוספת מעל הסיסמה.

## פיתוח מקומי

```bash
npm install
cp .dev.vars.example .dev.vars   # למלא ערכים מקומיים
npm run dev:api                  # Functions + R2 מקומי על 8788
npm run dev                      # Vite על 5173, ‏/api עובר ל-8788
```

ב-`wrangler pages dev` נוצר R2 מקומי (סימולציה), כך שאפשר לבדוק בלי לגעת בקבצים האמיתיים.

## מגבלות ידועות
- PDF עם עמודים מסובבים (rotation) נדחה בהעלאה. צריך לשמור אותו מחדש בלי סיבוב.
- PDF מוצפן או נעול לעריכה עלול לא להיטען. במקרה כזה מדפיסים אותו מחדש ל-PDF.
- פרטי הלקוח נכתבים במסמך כתמונה (כדי שעברית ומספרים יוצגו נכון), ולכן הם לא ניתנים לחיפוש כטקסט ב-PDF.
